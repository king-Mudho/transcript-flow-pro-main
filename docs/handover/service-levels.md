# Draft service levels (to discuss with MSU)

These are proposals, not commitments yet.

| Area | Proposed level |
| --- | --- |
| Website availability | 99.5% per month, measured by the uptime monitor on `/api/health/`, excluding announced maintenance (Sundays 22:00–24:00) |
| Support hours | Monday to Friday 08:00–17:00, Saturday 08:00–12:00 (Harare time), WhatsApp +263 71 446 0652 |
| Graduate enquiries | First reply within 4 working hours |
| Submission to MSU | Requests handed in to MSU within 2 working days of being received (with verified clearance) |
| Collection from MSU | Released documents collected within 2 working days of MSU marking them ready |
| Harare delivery | Out with a driver within 2 working days of collection from MSU |
| Zimpost dispatch | Sent within 2 working days of the deposit being paid |
| Incidents | Site down: response within 1 hour in support hours; data breach: MSU told within 72 hours |
| Reporting | Monthly report to MSU by the 5th working day of the next month |
| Backups | Nightly; restore tested every quarter |

The stage-warning days in Settings can be set to these targets so late
requests turn amber and red in the workspace.
